
# Atividade Prática – Introdução à Engenharia de Requisitos

## Objetivo

Compreender a importância da Engenharia de Requisitos por meio da identificação dos requisitos de um sistema de controle de alunos.

---

# Usuários do Sistema

* Administrador da escola
* Secretário(a)
* Professor(a)
* Aluno(a)

---

# Requisitos Funcionais

| Código | Requisito                                                            |
| ------ | -------------------------------------------------------------------- |
| RF01   | O sistema deve permitir cadastrar novos alunos.                      |
| RF02   | O sistema deve permitir consultar os dados dos alunos cadastrados.   |
| RF03   | O sistema deve permitir atualizar ou excluir informações dos alunos. |

---

Requisitos Não Funcionais

| Código | Requisito                                                                          |
| ------ | ---------------------------------------------------------------------------------- |
| RNF01  | O sistema deve possuir autenticação por login e senha para proteger os dados.      |
| RNF02  | O sistema deve apresentar uma interface simples, organizada e de fácil utilização. |

---

#  Importância do Levantamento de Requisitos

O levantamento de requisitos é importante pra compreender as necessidades dos usuários antes do desenvolvimento do software.

---

# Conclusão

A Engenharia de Requisitos é uma etapa fundamental no desenvolvimento de software, pois define as funcionalidades e características necessárias para que o sistema seja eficiente, seguro e atenda às necessidades dos seus usuários.
