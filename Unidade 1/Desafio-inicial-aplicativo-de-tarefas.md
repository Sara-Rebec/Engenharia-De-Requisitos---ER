# Cenário da Atividade
---
Imagine que você e sua dupla trabalham em uma Software
House. Seu primeiro cliente faz apenas o seguinte pedido: "Preciso de um aplicativo de Lista de Tarefas (To Do)."

Missão em Dupla: Listem todas as funcionalidades que esse
aplicativo deve possuir.
---



# Funcionalidades do Aplicativo To Do

| FN  | Funcionalidade            | Descrição                                                     |
| :-: | ------------------------- | ------------------------------------------------------------- |
| F01 | Cadastro de usuário       | Permite criar uma conta no sistema.                           |
| F02 | Login e logout            | Permite autenticar e encerrar a sessão do usuário.            |
| F03 | Recuperação de senha      | Possibilita redefinir a senha da conta.                       |
| F04 | Criar tarefa              | Permite adicionar novas tarefas à lista.                      |
| F05 | Editar tarefa             | Permite alterar informações de uma tarefa existente.          |
| F06 | Excluir tarefa            | Remove uma tarefa da lista.                                   |
| F07 | Marcar como concluída     | Permite indicar que uma tarefa foi finalizada.                |
| F08 | Definir data e horário    | Permite adicionar prazo para a tarefa.                        |
| F09 | Adicionar descrição       | Permite incluir detalhes sobre a tarefa.                      |
| F10 | Definir prioridade        | Classifica a tarefa como baixa, média ou alta prioridade.     |
| F11 | Categorizar tarefas       | Organiza tarefas por categorias ou etiquetas.                 |
| F12 | Pesquisar tarefas         | Localiza tarefas por nome ou palavra-chave.                   |
| F13 | Filtrar tarefas           | Exibe tarefas conforme prioridade, data ou status.            |
| F14 | Ordenar tarefas           | Organiza as tarefas por data, prioridade ou ordem alfabética. |
| F15 | Notificações              | Envia lembretes sobre tarefas próximas do vencimento.         |
| F16 | Visualizar tarefas do dia | Mostra apenas as tarefas programadas para o dia atual.        |
| F17 | Histórico de tarefas      | Exibe as tarefas já concluídas.                               |
| F18 | Sincronização             | Mantém as tarefas sincronizadas entre dispositivos.           |
| F19 | Alteração de perfil       | Permite atualizar dados do usuário.                           |
| F20 | Modo escuro               | Disponibiliza um tema escuro para o aplicativo.               |
| F21 | Compartilhar tarefas      | Permite compartilhar tarefas com outros usuários.             |
| F22 | Criar subtarefas          | Possibilita dividir uma tarefa em etapas menores.             |
| F23 | Favoritar tarefas         | Destaca tarefas importantes.                                  |
| F24 | Barra de progresso        | Exibe o percentual de tarefas concluídas.                     |
